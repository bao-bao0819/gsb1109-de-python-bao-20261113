# 设施轮廓整体平移核对工具

用于核对供方“新旧两批设施轮廓只是整体平移”的说法。工具基于 pygeoif
解析 WKT / GeoJSON 轮廓，根据已有对应的控制顶点和每点误差界，给出：

- 共同平移 `(dx, dy)` 的允许范围（各控制证据位移盒的交集）；
- 能唯一匹配的轮廓，以及仍有多种对应的轮廓；
- 重复形状下的一对一分配校验（两件设施不能都认给同一件）；
- 不存在共同平移时，一组互相冲突的控制证据及其位移盒。

## 数据格式

JSON 文件，轮廓可用 WKT 字符串或 GeoJSON geometry 对象：

```json
{
  "tolerance": 0.1,
  "old": [
    {"id": "F1", "geometry": "POLYGON((0 0, 4 0, 4 3, 0 3))"},
    {"geometry": "POLYGON((0 10, 2 10, 1 12))"}
  ],
  "new": [
    {"id": "F1", "geometry": "POLYGON((2.05 1, 6.05 1, 6.05 4.05, 2.05 4.05))"}
  ],
  "known_pairs": [
    {"old_id": "F1", "new_id": "F1", "tolerance": 0.05}
  ]
}
```

- `tolerance` 支持标量或 `{"x": ex, "y": ey}`，单条记录可用自己的
  `tolerance` 覆盖；`known_pairs` 里的配对也可单独给误差界。
- 新旧两批中相同 `id` 的轮廓自动视为已知控制对应；缺号轮廓用
  `old#序号` / `new#序号` 标记。
- 误差界按分量解释：配对顶点满足
  `|(新顶点 - 旧顶点) - (dx, dy)| <= 误差界`。

## 运行

```bash
.venv/bin/python -m translation_audit examples/dataset_consistent.json
.venv/bin/python -m translation_audit examples/dataset_conflict.json --json
```

## 判定方法

1. 每个候选旧/新轮廓对，把顶点按坐标排序后逐点配对，每对顶点产生一个
   位移盒 `[dx-ex, dx+ex] x [dy-ey, dy+ey]`；全部顶点位移盒的交集就是
   该轮廓对的可行平移盒，交集为空则该配对不成立。
2. 按几何类型、线性部件数和顶点数把同形轮廓分组，枚举组内全部一对一
   完美分配（增广路思想），保证重复形状不会两件认一件。
3. 已知控制对应是硬约束：枚举时强制锁定，其他轮廓不得占用其目标。
4. 跨组组合所有一对一分配，与全部控制证据的位移盒再取交集：
   - 交集非空 → 存在能解释全批的共同平移，输出允许范围；
   - 交集为空 → 输出最小冲突证据集（位移盒互不相交的控制对）。
5. 某旧轮廓在所有可行分配中只指向一个新轮廓即唯一匹配，否则列入
   多对应清单；无法分配的轮廓列入未匹配清单。

## 局限

- 顶点按坐标排序后逐点配对，不依赖环的起点和方向；若两件轮廓顶点集合
  相同但连接顺序不同，会被视为可平移对应，需要人工结合拓扑复核。
- 误差界是逐顶点、逐分量的绝对界，不支持旋转、缩放或相关误差模型。
- 组内一对一分配用穷举实现，适合单件设施轮廓顶点/重复件数量有限的批次；
  重复件数量很大时应改用带权二分图匹配。
