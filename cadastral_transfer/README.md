# cadastral_transfer — 新旧宗地面积转移表

从两个地籍交付批次的几何目录出发, 按**真实几何重叠**计量面积流向,
不按编号延续身份(旧编号可能被回收重用)。纯 Python 实现, 只依赖
`pygeoif`(用于读取 GeoJSON/WKT), 无需 shapely。

## 用法

```bash
python -m cadastral_transfer 旧批次目录/ 新批次目录/ -o 输出目录/
```

每个批次目录存放 `.geojson` / `.json` / `.wkt` 文件; 宗地编号取自
feature 的 `id` 或 properties 的 `id` / `name` / `宗地编号`, 缺省用文件名。
编号仅作报表标签, 不参与任何匹配。

## 计量口径

平面沿所有顶点与边交点的 x 坐标切成竖直条带; 条带内各宗地的覆盖
格局不变, 任何"属于哪些宗地"的组合面积都按中点精确积分, 因此:

- **只贴边不算转移** —— 共边接触面积为零, 自然不计入;
- **一拆多 / 多并一** —— 重叠多少记多少, 与宗地数量无关;
- **旧批内部争议** —— 被两宗以上旧宗地同时覆盖的区域单列"争议",
  不计入任何去向, 并在 `争议明细.csv` 给出逐对重叠量;
- **退界** —— 旧宗地未被任何新宗地覆盖的部分;
- **新增填土** —— 新宗地没有任何旧宗地来源的部分, 单列来源。

## 对账恒等式

每一旧宗地: `原面积 = 去向合计 + 退界 + 争议 + 新批重叠`
每一新宗地: `新面积 = 来源合计 + 新增填土 + 涉旧争议 + 新批重叠`

两表均附"校验差"列, 应为 0(或浮点噪声量级)。"新批重叠"仅当新批
宗地互相重叠时非零, 正常交付应为 0。

## 输出

- `转移矩阵.csv` —— 旧宗地 × 新宗地的转移面积
- `旧批核算.csv` —— 每旧宗地的去向/退界/争议/校验
- `新批核算.csv` —— 每新宗地的来源/填土/涉旧争议/校验
- `争议明细.csv` —— 批内逐对重叠面积

示例数据见 `examples/cadastral/`, 测试见 `tests/test_cadastral_transfer.py`。
